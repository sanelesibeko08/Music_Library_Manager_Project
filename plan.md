In this project we will apply core objecy-oriented programming concepts in Python to build a music library system.
We will design and implement multiple related classes, use encapsulation, properties, inheritance, and polymorphism, and manage 
collections of objects. 
This project will:
•	Create and test Python classes to represent tracks and audio content.
•	Implement instance methods, class attributes, and data validation.
•	Use properties to manage and protect internal state.
•	Apply inheritance and polymorphism to model different track types.
•	Build playlists to manage and interact with collections of objects.
•	Use an AI coding assistant to generate, extend, and test code.
